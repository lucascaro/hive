On Windows and Linux, Ctrl+Shift+↑/↓ now reorders the active session in a grid too, as ⇧⌘↑/↓ already did on macOS. Before, in a grid it only moved between tiles like Ctrl+↑/↓. Every shortcut hint in the app (help overlay, palette, status bar, tooltips) is now derived from the actual key bindings.
