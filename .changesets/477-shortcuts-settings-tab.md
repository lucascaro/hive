Settings → Shortcuts lets you rebind any command, including plugin commands: press a key to add it, give a command several keys or none, and reset one command or all of them. A key another command already uses is flagged on both rows and has to be reassigned or cancelled before you can save. A plugin key that clashes with a built-in one shows as a conflict instead of being dropped silently, and a command left without its key after an upgrade is flagged too. Keys macOS or the terminal reserve are refused with the reason, and keys that programs in a session also use show a warning. The terminal's own editing keys are listed but can't be changed. New keys work right away, in every window, on the native menu, and in every hint.
