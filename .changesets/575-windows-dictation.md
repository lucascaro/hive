Dictate into a session on Windows: while a Hive window is open, Ctrl+Shift+Space anywhere opens the same confirm-before-send dictation box as on macOS. Enter sends, Shift+Enter starts a new line, Up/Down picks the target session and Esc discards. With Handy installed, Settings › Dictation offers the same "Start Handy recording when the dictation box opens" switch. Installing this update restarts Hive's daemon, which ends running sessions.
