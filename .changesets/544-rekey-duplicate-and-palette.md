Three default shortcuts moved to make room for Go to session on ⌘P: Duplicate Session is now ⌘K (was ⌘P), Duplicate Session (choose tool) is ⇧⌘K (was ⇧⌘P), and the command palette is ⇧⌘P (was ⇧⌘K). Ctrl replaces ⌘ on Windows and Linux. Shortcuts you have rebound in Settings › Shortcuts are unchanged.
