Go to session. ⌘P (Ctrl+P on Windows and Linux) opens a finder over every session in every project, including collapsed ones. Type part of a session's name, window title, git branch or project name — it matches loosely, so `fab` finds `fix-auth-bug` — and press Enter to jump there. With nothing typed, the session you were just in comes first, so ⌘P then Enter flips back. Also in the command palette as "Go to Session…".
