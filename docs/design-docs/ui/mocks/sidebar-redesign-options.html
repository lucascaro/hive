04Polish items — all eight, each one selectable

Every suggestion from round 1 is here, whether or not you ticked it, each with a mock, a verdict and its own notes box. Your five are pre-marked In; the three you skipped are unset so you can look at them properly. One is withdrawn — my error, explained on its card.

1 · Strip the project prefix from titles withdrawn — my error

I proposed this off a sample title I invented. There is no project prefix: internal/session/session.go:42 passes the program's OSC 0/2 title straight through, and lib/term-title.ts only suppresses a title identical to the session name. Hive never prepends anything. Every sample title on this page has been corrected to drop the fake hive — . If your real titles do repeat a prefix, it's your shell or agent emitting it — stripping that is a different and riskier feature (we'd be editing text we don't own). Say the word and I'll scope it honestly.

Verdict

7 · Hide default colour swatches you skipped this — and it has a catch

Every row spends 10px plus its gap on a colour chip. The catch, checked before mocking it this time: internal/registry/create.go:321 auto-assigns a colour to every session via pickColor(), and nothing anywhere records whether that colour was auto-picked or chosen by you. So “hide the default ones” is not free — it needs a new colorExplicit bit on the entry, set when the swatch is used, persisted with the session. Small, but it is a daemon change, not a CSS one. The cheap version is the right-hand mock: show the swatch on hover and on rows that belong to a shared worktree, hide it otherwise.
