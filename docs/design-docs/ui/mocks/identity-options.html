Decision: B is the default preset (hive-dark). A, C and the baseline ship as selectable presets (native, terminal, classic).

Same screen, same content, four token sets. Every mock reads only --h-* variables — which is also the mechanism that makes user theming (palette, fonts) possible later. Terminal content is stand-in text.

A · native-adjacent Recedes into the OS

Read: lifted greys instead of pure black, system font, soft 6px radii, filled selection (no bar), bordered buttons — cues from Finder/VS Code/Zed sidebars. Brand goes neutral; the amber is spent once, on accent. Attention gets its own hue so it's not confused with selection. Cost: least distinctive; on Linux/Windows "native" is a moving target so it reads as "generic-good."

B · own brand, dev-tool Linear / Warp lineage

Read: cool-biased near-black (blue-tinted greys, not neutral), IBM Plex Sans for UI + JetBrains Mono for brand/terminal, uppercase tracked project headers, 2px selection bar, warm amber accent kept from today so existing users still recognize it. Cost: ships two webfonts (~150KB, must be bundled — Wails has no CDN), most CSS to write, and a wrong call here is visible everywhere.

C · terminal-first minimal tmux with a sidebar

Read: everything monospace, square corners, no fills — hierarchy comes from weight and a single 1px accent rule. Near-monochrome; busy = grey, attention = the only saturated thing on screen, which makes "needs you" impossible to miss. Cost: monospace UI wastes width in a 200px sidebar (long session names truncate sooner); dialogs (Settings, Worktrees) get austere fast; least approachable for non-terminal people.

note What's shared regardless of pick

All three fix the same defects: one token layer (≈40 variables) replacing 51 literals; a 5-step type scale replacing 12 sizes; separate roles for brand / accent / selection / attention / ok / error; a spacing scale. The pick decides values, not the architecture — and user theming = overriding those same variables from a settings file. A light theme becomes a second value set, not a second stylesheet.
